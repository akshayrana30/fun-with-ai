# fun-with-ai
Repo for random scripts and Jupyter notebooks to make small applications just for practice and fun.

## Model Discovery

To explore and list all AI/ML models in this repository, use the model discovery utility:

```bash
python3 list_models.py
```

This will automatically scan the repository and display:
- All model implementations across different frameworks
- Saved model files
- Model architectures and types
- Frameworks used (TensorFlow, Keras, scikit-learn, etc.)

For detailed information about all models, see [MODELS.md](MODELS.md).
